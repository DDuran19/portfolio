# Solo Full-Stack Developer

I build web apps, POS systems, and marketing sites end-to-end — from requirements to production on Cloudflare's edge network. Every project below was designed, built, and deployed by me alone.

---

## Tech Stack

**Core:** SvelteKit, TypeScript  
**UI & Styling:** TailwindCSS, DaisyUI, shadcn-svelte  
**Database:** Cloudflare D1 (serverless SQL), PocketBase  
**Infrastructure:** Cloudflare Workers & Pages
